# ข้ามถนน (Cross the Road)

เกม 2.5D ด้วย pygame: พาคน 10 คนข้ามทางม้าลายไปฝั่งปลอดภัยให้ได้ตามเป้าของแต่ละด่าน
แต่ละคนมีความสามารถต่างกัน โดนรถชนแล้วเลือดหก รถที่ลื่นเลือดจะชนกันเป็นซาก แล้วโดรนจะมายกออก

**Demo (YouTube):** https://www.youtube.com/watch?v=t8O9S4TXOWM

## วิธีรัน

```
pip install pygame
python cross_the_road.py
```

ต้องใช้ Python 3.9 ขึ้นไป เกมหาฟอนต์ภาษาไทยในเครื่องเอง (Windows/macOS มีอยู่แล้ว)

## วิธีเล่น

| ปุ่ม | ทำอะไร |
|---|---|
| คลิกซ้ายที่คน / ปุ่ม 1–9, 0 | เดินข้าม / หยุด |
| คลิกขวาที่คน / Shift + เลข | ใช้ความสามารถ |
| Shift + คลิก | เลือกหลายคน ปล่อย Shift แล้วเดินพร้อมกัน (Esc = ล้าง) |
| G / Space | ทุกคนเดิน / ทุกคนหยุด |
| P | หยุดชั่วคราว |
| R / N | เริ่มด่านใหม่ / ด่านถัดไป (หลังผ่านด่าน) |

| ตัวละคร | ความสามารถ |
|---|---|
| ตำรวจจราจร | ยกป้ายหยุดรถเลนตัวเองและเลนถัดไป 3 วินาที |
| นักวิ่ง | วิ่งเร็ว x2.2 ชั่วคราว แล้วจะเหนื่อย |
| คุณยาย | รถที่อยู่ใกล้ชะลอเอง |
| เด็ก | อยู่คนเดียวเกิน 2 วินาทีจะตกใจเดินมั่ว |
| คนแข็งแรง | อุ้ม / วางคนอื่น |
| ประชาชน | บางคนถือถังน้ำมัน โดนชนแล้วระเบิด |

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `cross_the_road.py` | คลาส `Game`: ตั้งค่า รับอินพุต game loop |
| `simulation.py` | `GameSimulation`: การเคลื่อนที่ การชน ผลแพ้ชนะ |
| `entities.py` | `Person`, `Car`, `Drone`, `Puddle`, `Fire`, `Particle` |
| `rendering.py` + `render_*.py` | `GameRenderer`: วาดทุกอย่าง ([รายละเอียด](docs/rendering.md)) |
| `geometry.py` | แปลงพิกัด 2.5D และวาดกล่อง 3 มิติ |
| `game_config.py` | ค่าคงที่: ขนาดจอ ด่าน รถ ตัวละคร สี |
| `fonts.py` | หาฟอนต์ภาษาไทย |
