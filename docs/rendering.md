# ระบบวาดภาพ (rendering)

| ไฟล์ | หน้าที่ |
|---|---|
| `rendering.py` | `GameRenderer.draw()` ลำดับการวาด 1 เฟรม |
| `render_cars.py` | วาดรถทุกชนิด |
| `render_people.py` | วาดคน (`PersonPose`) |
| `render_effects.py` | ของบนพื้น (เลือด เงา วงใต้เท้า), เลนที่ถูกหยุด, โดรน, ไฟ, เศษชิ้นส่วน, ข้อความลอย, ข้อความแจ้งเตือน |
| `render_ground.py` | พื้นหลัง (ตึก ทางเท้า ถนน ทางม้าลาย) วาดครั้งเดียวตอนเปิดเกม + รอยเบรก |
| `render_hud.py` | แถบด้านล่าง + กล่องกลางจอ (หน้าเริ่ม ชนะ แพ้ หยุดชั่วคราว) |
| `geometry.py` | `project()`, `local()`, `draw_box()` ใช้ร่วมกันทุกไฟล์ |
| `fonts.py` | หาฟอนต์ที่แสดงภาษาไทยได้ |

ไม่ใช้ไฟล์รูปเลย ทุกอย่างวาดด้วย `pygame.draw`

`simulation.py` ไม่ import pygame แล้ว: รอยเบรกที่เคยวาดใน simulation ตอนนี้ simulation แค่เก็บเส้นไว้ใน `skid_segments`
และนับจำนวนครั้งที่ต้องจางใน `skid_fades_pending` แล้ว `draw_skid_marks()` เป็นคนวาด

## 1 เฟรมวาดอะไรบ้าง

```
draw()
 ├─ draw_ground_layers()          ถนน (วาดไว้ครั้งเดียว) + draw_skid_marks() + draw_decals() + draw_frozen_lanes()
 ├─ update_hover()                เมาส์ชี้คนไหนอยู่
 ├─ draw_depth_sorted_objects()   รถ คน ไฟ  ── painter's algorithm
 ├─ draw_flying_objects()         รถที่ถูกยก + โดรน
 ├─ draw_particles()
 ├─ draw_floaters() / draw_impacts()
 ├─ draw_flash()
 │      ↑ วาดลง world_canvas (ภาพนอกจอ)
 ├─ present_world_with_shake()    แปะ world_canvas ลงจอ + จอสั่น
 │      ↓ วาดลงจอจริง จึงไม่สั่นตาม
 ├─ draw_toasts()
 ├─ draw_heads_up_display()
 └─ draw_overlay_card()
```

## อัลกอริทึมหลัก

**1. ภาพ 2.5D: `project()`**

```
screen_x = x
screen_y = ORIGIN_Y + y × VERTICAL_SCALE − z × HEIGHT_SCALE
```

y คือความลึกบนพื้น (ไกล → อยู่สูงบนจอ) z คือความสูงจากพื้น (สูง → ถูกยกขึ้น)
ต้องลบ z เพราะแกน y ของจอนับลงล่าง

**2. ของใกล้บังของไกล: painter's algorithm ใน `draw_depth_sorted_objects()`**

ใส่รถ คน ไฟ ลงลิสต์เดียวพร้อมค่า y แล้ว `sort` วาดจากไกลมาใกล้ ของที่วาดทีหลังทับของที่วาดก่อน
ศพใช้ y − 0.5 ให้อยู่ใต้คนที่ยืนจุดเดียวกัน
รถที่โดรนยกกับโดรนลอยอยู่เหนือทุกอย่าง จึงวาดแยกทีหลังใน `draw_flying_objects()`

**3. กล่อง 3 มิติ: `draw_box()`**

1. `box_corners()` หามุม 4 มุมของกล่องที่หมุนแล้ว (rotation matrix: cos/sin)
2. แต่ละด้านหา normal (ขอบหมุน 90°) แล้วใช้ dot product กับทิศจากจุดกลาง เช็กให้ normal ชี้ออกนอก
3. วาดเฉพาะด้านที่ normal ชี้เข้าหากล้อง (normal_y > 0) = back-face culling
4. สีด้านข้างเข้มอ่อนตาม normal_x จึงดูเหมือนมีแสง
5. วาดฝาบนปิดท้าย

รถแต่ละคันคือกล่องหลายชิ้นซ้อนกัน ตำแหน่งทุกชิ้นคิดจากจุดกลางรถผ่าน `local()`
รถหมุนเมื่อไหร่ทุกชิ้นหมุนตาม ส่วน `car.lift` ยกทั้งคันขึ้นตอนโดรนยก

**4. คนทุกท่าด้วยโค้ดชุดเดียว: `PersonPose`**

อวัยวะทุกส่วนวางบน "แกนลำตัว" ที่เอียงด้วยมุม `pose`

- `pose = 0` ยืน: ความสูงบนลำตัวอยู่แกน z
- `pose = π/2` นอน: ความสูงกลายเป็นระยะแนวนอน

`PersonPose.point(height, offset)` ใช้ sin/cos ของ pose แปลงตำแหน่งบนลำตัวเป็นจุดบนจอ
จึงวาดได้ทั้งยืน เดิน ล้ม นอน ถูกแบก และตาย
ท่าเดินใช้ sine wave: `|sin|` ทำให้ตัวเด้ง ส่วน `sin` ทำให้ขาแกว่งสลับกัน คนเจ็บเดินกะเผลก (ขาข้างหนึ่งแกว่งน้อย)

**5. จอสั่น: `present_world_with_shake()`**

แปะ `world_canvas` ลงจอโดยเลื่อนแบบสุ่มตาม `active_surface_shake_strength` (ค่านี้ลดลงเองใน simulation)
HUD วาดหลังขั้นนี้จึงนิ่ง

**6. Cache: `render_cache()`**

ฉากหรี่จอใน `center_card()` และป้ายคำ "ปั้ก!" พร้อมขอบดำ สร้างครั้งเดียวแล้วใช้ซ้ำ
ส่วน `rotozoom` ยังทำทุกเฟรมเพราะขนาดเปลี่ยนตามเวลา

**7. ฟอนต์ไทย: `fonts.py`**

ลองฟอนต์ในเครื่องทีละตัว วาด "ก" กับ "ข" แล้วเทียบพิกเซล ถ้าเหมือนกันแปลว่าไม่มีอักษรไทย (วาดเป็นกล่องว่างทั้งคู่)
ใช้ตัวแรกที่ผ่าน แล้วเก็บไว้ใน cache

## ที่ยังไม่ได้แก้

- #1 ไฟ ใบพัดโดรน ดาวมึน ใช้ `pygame.time.get_ticks()` (เวลาจริง) ยังขยับตอนกดพัก
- #2 `draw()` อ่านเมาส์เอง (`update_hover()`)
- #3 `self.hover` ไม่ได้ตั้งค่าใน `__init__`
- `draw_toasts()` render ข้อความใหม่ทุกเฟรม (cache ตรง ๆ ไม่ได้เพราะข้อความมีตัวเลข HP ปน cache จะโตไม่หยุด)
