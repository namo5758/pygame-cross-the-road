# ระบบวาดภาพ (rendering)

ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|---|---|
| `rendering.py` | คลาส `GameRenderer` วาดทุกอย่างใน 1 เฟรม |
| `geometry.py` | คณิตศาสตร์: `project()` แปลงพิกัด, `local()` หมุนจุด, `draw_box()` วาดกล่อง 3 มิติ |
| `fonts.py` | หาฟอนต์ที่แสดงภาษาไทยได้ |

เกมนี้ไม่ใช้ไฟล์รูปเลย ทุกอย่างวาดด้วย `pygame.draw` (polygon, line, circle, ellipse)

## 1 เฟรมวาดอะไรบ้าง

`Game.run()` เรียก `draw()` ทุกเฟรม ซึ่งวาดจากชั้นล่างขึ้นชั้นบน

```
draw()
 ├─ draw_ground_layers()          ถนน (วาดไว้ครั้งเดียว) + รอยล้อ + คราบ/เงา + เลนที่ถูกหยุด
 ├─ update_hover()                เมาส์ชี้คนไหนอยู่
 ├─ draw_depth_sorted_objects()   รถ คน ไฟ  ── painter's algorithm
 ├─ draw_flying_objects()         รถที่ถูกยก + โดรน
 ├─ draw_particles()              เศษชิ้นส่วน
 ├─ draw_floaters() / draw_impacts()   ตัวเลข/คำว่า "ปั้ก!" ลอยขึ้น
 ├─ draw_flash()                  แฟลชขาวตอนระเบิด
 ├─ present_world_with_shake()    แปะโลกลงจอ + จอสั่น
 ├─ draw_toasts()                 ข้อความแจ้งเตือนด้านบน
 ├─ draw_heads_up_display()       แถบด้านล่าง (สถิติ รายชื่อ ข้อมูลคน วิธีเล่น)
 └─ draw_overlay_card()           หน้าเริ่ม / ชนะ / แพ้ / หยุดชั่วคราว
```

ทุกอย่างก่อน `present_world_with_shake()` วาดลง `world_canvas` (ภาพนอกจอ)
ส่วนที่อยู่หลังจากนั้นวาดลงจอจริงโดยตรง จึงไม่สั่นตาม

## อัลกอริทึมหลัก

**1. ภาพ 2.5D: `project()` ใน `geometry.py`**

```
screen_x = x
screen_y = ORIGIN_Y + y × VERTICAL_SCALE − z × HEIGHT_SCALE
```

y คือความลึกบนพื้น (ไกล → อยู่สูงบนจอ) ส่วน z คือความสูงจากพื้น (สูง → ถูกยกขึ้นบนจอ)
`unproject()` ทำกลับด้าน ใช้แปลงตำแหน่งเมาส์เป็นจุดบนพื้น (สมมติ z = 0)

**2. ของใกล้บังของไกล: painter's algorithm ใน `draw_depth_sorted_objects()`**

ใส่รถ คน ไฟ ลงลิสต์เดียวกันพร้อมค่า y แล้ว `sort` จากน้อยไปมาก วาดจากไกลมาใกล้
ของที่วาดทีหลังทับของที่วาดก่อน ศพใช้ y − 0.5 เพื่อให้อยู่ใต้คนที่ยืนจุดเดียวกัน

**3. กล่อง 3 มิติ: `draw_box()` ใน `geometry.py`**

1. หามุม 4 มุมของกล่องที่หมุนแล้ว (`box_corners()` ใช้ cos/sin)
2. แต่ละด้านหา normal แล้วใช้ dot product เช็กให้ชี้ออกนอกกล่อง
3. วาดเฉพาะด้านที่หันเข้ากล้อง (normal_y > 0) = back-face culling
4. สีด้านข้างเข้มอ่อนตาม normal_x จึงดูเหมือนมีแสง
5. วาดฝาบนทับสุดท้าย

รถทุกคันคือกล่องหลายชิ้นซ้อนกัน ตำแหน่งแต่ละชิ้นคิดจากจุดกลางรถผ่าน `local()` รถหมุนเมื่อไหร่ทุกชิ้นหมุนตาม

**4. คนทุกท่าด้วยโค้ดชุดเดียว: `PersonPose` ใน `rendering.py`**

อวัยวะทุกส่วนวางบน "แกนลำตัว" ที่เอียงด้วยมุม `pose`

- `pose = 0`: ยืน ความสูงอยู่แกน z
- `pose = π/2`: นอน ความสูงกลายเป็นระยะแนวนอน

`PersonPose.point(height, offset)` ใช้ sin/cos ของ pose แปลงความสูงบนลำตัวเป็นจุดบนจอ
จึงวาดได้ทั้งยืน เดิน ล้ม นอน ถูกแบก และตาย การเดินใช้ sine wave:
`|sin|` ทำให้ตัวเด้ง ส่วน `sin` ทำให้ขาแกว่งสลับกัน

**5. จอสั่น: `present_world_with_shake()`**

แปะ `world_canvas` ลงจอโดยเลื่อนแบบสุ่มตามค่า `active_surface_shake_strength`
(ค่านี้ลดลงเองในฝั่ง simulation) HUD วาดทีหลังจึงนิ่ง

**6. ฟอนต์ไทย: `fonts.py`**

ลองฟอนต์ในเครื่องทีละตัว วาด "ก" กับ "ข" แล้วเทียบพิกเซล ถ้าเหมือนกันแปลว่าฟอนต์ไม่มีอักษรไทย
(วาดเป็นกล่องว่างเหมือนกันทั้งคู่) ใช้ตัวแรกที่ผ่าน แล้วเก็บไว้ใน cache
